# 🎬 Movie Recommender

A movie recommendation web app. Pick a film you like and get similar ones, or rate a few movies and get personal recommendations with a reason for each pick ("Because you liked Inception and The Matrix").

Built with **Python, Flask, scikit-learn and SciPy**. It also has a command-line tool and a JSON API.

## Features
- **Find similar movies:** search a title and get 10 matches with an explanation (shared genres, same director, "viewers who liked one often liked the other")
- **Recommend for me:** rate movies you have seen (1 to 5 stars) and get personalised picks. Low ratings push similar movies away
- **Top rated:** best movies overall or per genre, using a weighted rating so films with few votes don't dominate
- **Taste slider:** blend *content* (story, genre, director) and *audience taste* (what other viewers rated)
- Fuzzy search ("godfater" finds *The Godfather*), responsive dark UI, JSON API, tests, GitHub Actions CI
- Works with the sample data or with **MovieLens** (see below)

## How it works

| Method | Idea |
|---|---|
| **Content-based** | Each movie becomes a TF-IDF vector from its genres, director, title and one-line story. Movies with a high cosine similarity are recommended. |
| **Collaborative (item-based)** | Ratings are centered on each viewer's average, then movies are compared using the viewers who rated both (adjusted cosine similarity). Similarities based on very few shared viewers are shrunk toward zero. |
| **Hybrid** | `score = alpha * content + (1 - alpha) * collaborative + small popularity prior`. The slider in the UI controls `alpha`. |
| **Personal profile** | Your ratings above 3 attract and below 3 repel, in both the content and collaborative parts. Movies you already rated are never recommended. |

## Quick start

Requires Python 3.9 or newer.

```bash
# 1. (optional) create a virtual environment
py -m venv .venv
.venv\Scripts\activate           # Windows
# source .venv/bin/activate        # macOS / Linux

# 2. install dependencies
pip install -r requirements.txt

# 3. start the web app
python app.py
```
Open **http://127.0.0.1:5000** in your browser. On Windows, use `py` instead of `python` if `python` doesn't work.

### All commands

| Command | What it does |
|---|---|
| `python app.py` | Start the web app |
| `python app.py --data path/to/folder --port 8000` | Use another dataset and port |
| `python recommend.py --similar "Inception"` | Movies similar to one title |
| `python recommend.py --rate "Inception=5" "Titanic=2"` | Recommendations from your ratings |
| `python recommend.py --user 12` | Recommendations for a viewer in the dataset |
| `python recommend.py --top --genre Comedy` | Top rated movies |
| `python evaluate.py` | Hold-out accuracy test of all methods |
| `python generate_dataset.py` | Regenerate the sample data |
| `python -m unittest discover -s tests -v` | Run the 18 tests |

## API

| Endpoint | Description |
|---|---|
| `GET /api/movies/search?q=incep` | Search titles (fuzzy) |
| `GET /api/movies/<id>/similar?n=10&audience=0.5` | Similar movies. `audience` is 0 (content only) to 1 (ratings only) |
| `POST /api/recommend` | Body: `{"ratings": {"7": 5, "17": 2}, "n": 10, "alpha": 0.5}` |
| `GET /api/top?genre=Comedy&n=10` | Top rated, optional genre |
| `GET /api/genres`, `/api/stats`, `/api/sample-user`, `/api/health` | Helpers |

Errors return HTTP 400 or 404 with `{"error": "..."}`.

## Results and the data (please read)

The included data in `data/` is a **sample**:
- `movies.csv`: 108 real films (title, year, genres, director) with one-line descriptions written for this project
- `ratings.csv`: **synthetic**. 400 made-up viewers with different tastes (favourite and disliked genres, old versus new films), about 9,000 ratings. They are generated by `generate_dataset.py`

Hold-out test (`python evaluate.py`): for each of 387 viewers, 20% of their ratings are hidden, 10 movies are recommended from the rest, and we check whether the hidden movies they liked (4 or 5 stars) appear.

| Method | Precision@10 | Recall@10 | Hit rate |
|---|---|---|---|
| Popularity only | 0.040 | 0.142 | 0.331 |
| Content-based | 0.051 | 0.191 | 0.408 |
| Collaborative | 0.044 | 0.162 | 0.367 |
| Hybrid (50/50) | 0.051 | 0.187 | 0.406 |

Personalised methods beat the popularity baseline. **Treat these numbers as a check that the pipeline works, not as real-world performance.** The synthetic viewers were generated to have genre-based taste, so personalisation is easier here than with real people. Results vary a little with the split seed, and the ranking between content and hybrid is not stable.

### Use real data (MovieLens)
1. Download **MovieLens ml-latest-small** from grouplens.org (check its license and terms of use before redistributing).
2. Run `python app.py --data path/to/ml-latest-small`.

The loader reads MovieLens' `movies.csv` and `ratings.csv` directly. MovieLens has no director or story text, so the content part uses genres and title words only. You can add `director` and `overview` columns to `movies.csv` to improve it. For large datasets (tens of thousands of movies) the first similarity lookups take a bit longer.

## Limitations
- The sample catalog is small, so recommendations are limited to 108 films
- No user accounts or saved profiles: ratings live in the browser page until you refresh
- Cold start: a movie with no ratings can only be matched by content
- Recommendations are suggestions, not facts. Match percentages are relative to the best candidate for that search
